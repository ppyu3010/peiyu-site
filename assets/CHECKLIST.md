# 素材清單

網站現在的結構：**載入畫面（刷門禁卡）→ 一面平面牆，牆上貼著你畫的圖樣 → 點圖樣展開 → 看該區的內容**。

已確定的三個區域：

| 區域 | 牆上的圖樣 | 展開後 |
|---|---|---|
| ABOUT ME / CONTACT | `about-contact.png` | 照片、自我介紹、聯絡方式 |
| DESIGN | `design.png` | 作品格狀列表 → 點作品看大圖與說明 |
| WRITING | `writing.png` | 文章列表 → 點文章閱讀 |

> 之後想加新區域（手作、專案經驗、電子報…）隨時告訴我，只要多畫一個圖樣就行。

---

## 通則

- 檔名請**完全照抄**：小寫英文、用 `-` 連接，不要空格和中文。
- 標「透明」的存成 **PNG（透明背景）**。
- 單張圖**不要超過 4096 px 寬**，網頁版 3200 px 寬已經很夠。
- 沒畫的項目，網站會用暫代形狀，不影響運作。
- 你的原始檔（AI／PSD／Procreate）放 `assets/_source-files/` 備份，我不會動。
- 每次新增或更換內容，**雙擊專案根目錄的「更新網站內容.command」**，再重新整理網頁；或直接告訴我，我來更新。

**一件作品 = 一個資料夾**，資料夾名稱用英文，例如 `2026-folk-weekly`。可參考 `_example-project`（底線開頭的資料夾會被忽略，是範例）。

```
04-design/
  2026-folk-weekly/
    info.md        ← 作品資訊（必要）
    cover.jpg      ← 列表上的縮圖、以及點開後放大的封面
```

| ✔ | 檔名 | 內容 | 建議 |

| ☐ | `info.md` | 標題、日期、角色、說明 | 見下方範本 |

**info.md 範本**

```

role: 平面設計／插畫
---

作品說明。空一行就是新的一段，會用細體（EL）顯示在標題下方。

## 小標題

也可以有小標題。
```

- `date` 決定排序（新到舊）跟分組用的年份，格式是 `YYYY-MM-DD`。
- 資料夾裡除了 `info.md`、`cover.jpg` 以外的圖片，會依**檔名順序**自動當成細節圖，顯示在說明文字下方，置中、統一高度，圖說先留空。

返回鍵：`assets/02-wall/ui/writing-back-button.png`（已放好）。

**一篇文章 = 一個資料夾**，名稱用「日期-英文短名」，例如 `2026-02-01-salt-literature`。可參考 `_example-article`。

```
05-writing/
  2026-02-01-salt-literature/
    index.md
```

**index.md 寫法**

```
---
title: 特色書屋情報十一選
date: 2026-02-01
source: 《鹽分地帶文學》第 120 期，2026 年 2 月
url: https://外部文章的網址
---
```

- `title`：第一行，粗體。
- `source`：第二行，想寫「收錄於……」就自己寫進去。
- `date`：只用來排序（新的在左上）。
- `url`：有的話，第二行最後出現跳轉按鈕；沒有就留空或整行刪掉。
- 如果想在網站內直接閱讀全文，就把全文寫在 `---` 下面；有內文時，篇名會變成可點擊。
